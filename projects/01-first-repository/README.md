# My First Repository

## About

This is my first Git repository. It contains a simple HTML page that I created while learning how to use Git and GitHub. The goal of this project is to understand the basic workflow: initializing a repository, staging files, committing changes, and pushing to a remote repository on GitHub.

## How to Run

Open `index.html` in any modern web browser. No server or build tools required.

```bash
open index.html
```

## Technologies

- HTML5
- CSS3
- Git
- GitHub

## What I Learned

- Initializing a Git repository with `git init`
- Checking repository status with `git status`
- Staging files with `git add`
- Committing changes with `git commit`
- Connecting to GitHub with `git remote add`
- Pushing code with `git push`
