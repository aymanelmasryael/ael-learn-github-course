# Contributing to First Repository

Thank you for considering contributing! Please follow these guidelines.

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git switch -c feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Code Style

- Follow the existing code style
- Write clear commit messages
- Add comments where necessary
- Test your changes before submitting

## Reporting Issues

Report issues at the repository's Issues page with a clear description and steps to reproduce.

## Code of Conduct

This project follows a Code of Conduct. Be respectful and constructive in all interactions.
