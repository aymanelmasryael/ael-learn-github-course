# Issue & Project Board Reference

This folder contains example templates and reference materials for GitHub Issues and Project Boards.

## Contents

- `.github/ISSUE_TEMPLATE/bug_report.md` — Bug report template
- `.github/ISSUE_TEMPLATE/feature_request.md` — Feature request template

## Example Milestones

- **v1.0.0** — Initial release (core features, basic functionality)
- **v1.1.0** — Enhancements (new features, UI improvements)
- **v2.0.0** — Major update (breaking changes, architecture overhaul)

## Example Project Board Columns

| Column | Purpose |
|--------|---------|
| Backlog | Ideas and tasks not yet prioritized |
| To Do | Tasks ready to be worked on |
| In Progress | Currently being worked on |
| Review | Awaiting code review / QA |
| Done | Completed tasks |
