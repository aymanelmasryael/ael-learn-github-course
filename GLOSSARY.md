# Git & GitHub Glossary

**Branch** — A parallel version of a repository.
**Clone** — A local copy of a remote repository.
**Commit** — A snapshot of changes in Git.
**Fork** — A personal copy of someone else's repository.
**Issue** — A bug report or feature request on GitHub.
**Merge** — Combining changes from different branches.
**Pull Request** — A proposal to merge changes into a repository.
**Remote** — A version of a repository hosted on GitHub.
**Repository** — A project folder tracked by Git.
**Staging** — Preparing changes for a commit.
